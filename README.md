# AppSculptor

Sketch your app's screens, then hand them to Claude as a picture **and** a written brief — so you don't have to describe the layout in words.

Open `index.html` in any browser. No build step, no install.

## How it works

1. **Add components** — nav bar, tab bar, buttons, text fields, lists, cards, toggles, chips, stat tiles, images, and a *Custom block* for anything else. Tap one to add it under the selected component.
2. **Edit** — click a component on the screen to change its text, style and options. Add a **Note for Claude** for behavior the picture can't show (it appears as a numbered pink marker).
3. **Screens & style** — add as many screens as you need. Pick phone, tablet or web, light or dark, an accent color and corner roundness.
4. **Export for Claude**
   - **Save image** — all screens side by side as one PNG, with numbered notes.
   - **Copy brief** — a Markdown description of every screen, component by component, top to bottom.
   - In your app-building thread, attach the image and paste the brief.

Projects autosave in the browser. Use **Save project file** / **Open project file** to move work between devices.

Keyboard: `Ctrl/Cmd+Z` undo, `Ctrl/Cmd+Shift+Z` redo, `Delete` removes, `Ctrl/Cmd+D` duplicates, `Alt+↑/↓` reorders.
